Conversación con IA opcional · Tareas guardadas en este dispositivo

1. Hablar con JP

Listo para conversar. Pulsa «Iniciar conversación».
Hola. Soy JP. Puedes decir «anota revisar las compras de ABC», «recuérdame llamar al cliente en 10 minutos», «qué tengo pendiente» o «terminé compras de ABC».

En modo conversación, JP vuelve a escuchar después de responder. Chrome puede detener el reconocimiento al apagar la pantalla o cambiar de aplicación. Si no escucha, utiliza «Hablar una vez».

2. Conexión de inteligencia artificial

Cuando configures el Worker de Cloudflare, JP podrá conversar de manera libre. Para tareas sigue utilizando los comandos de registro, consulta y cierre.

IA no configurada. Los comandos de tareas siguen disponibles.

En este prototipo, la dirección del Worker y tu código de acceso se guardan localmente en Chrome. Usa un código exclusivo de JP; no reutilices contraseñas. El Worker debe ser privado mediante ese código, pero esto no sustituye una autenticación profesional.

3. Tareas 0 pendientes

Se conservan en este navegador y dispositivo. JP 4.0 conserva los pendientes de JP 3.0 en este navegador. No se sincronizan entre dispositivos.

4. Avisos de prueba

Limitación: los avisos programados en esta versión solo se comprueban mientras la página esté abierta y activa. No son recordatorios confiables con la pantalla bloqueada o la aplicación cerrada. Después construiremos un servicio de notificaciones persistentes.

Privacidad: no introduzcas información confidencial real de clientes durante las pruebas. El reconocimiento de voz de Chrome podría utilizar servicios de transcripción externos. La IA solo recibe el texto de tus consultas y, para contextualizar respuestas, una lista breve de tareas. No incluyas datos sensibles de clientes en esta etapa.
